# GitHub CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Set up GitHub Actions to run lint + tests on PRs/main and deploy to GitHub Pages on main.

**Architecture:** Single workflow with three sequential jobs (lint → test → deploy). Uses Bun natively with `oven-sh/setup-bun`. Deploy uses GitHub's official `actions/deploy-pages`.

**Tech Stack:** GitHub Actions, Bun 1.3.11, Node 24, Playwright, Vitest

**Spec:** `docs/superpowers/specs/2026-03-19-github-ci-design.md`

### Task 2: Create the GitHub Actions workflow

**Files:**
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: Create the .github/workflows directory**

```bash
mkdir -p .github/workflows
```

- [ ] **Step 2: Write the workflow file**

Create `.github/workflows/ci.yml`:

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: oven-sh/setup-bun@v2
        with:
          bun-version: '1.3.11'

      - uses: actions/setup-node@v4
        with:
          node-version: '24'

      - uses: actions/cache@v4
        with:
          path: ~/.bun/install/cache
          key: bun-${{ runner.os }}-${{ hashFiles('bun.lock') }}
          restore-keys: bun-${{ runner.os }}-

      - run: bun install

      - run: bun run lint

      - run: bun run check

  test:
    needs: lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: oven-sh/setup-bun@v2
        with:
          bun-version: '1.3.11'

      - uses: actions/setup-node@v4
        with:
          node-version: '24'

      - uses: actions/cache@v4
        with:
          path: ~/.bun/install/cache
          key: bun-${{ runner.os }}-${{ hashFiles('bun.lock') }}
          restore-keys: bun-${{ runner.os }}-

      - uses: actions/cache@v4
        with:
          path: ~/.cache/ms-playwright
          key: playwright-${{ runner.os }}-${{ hashFiles('bun.lock') }}
          restore-keys: playwright-${{ runner.os }}-

      - run: bun install

      - run: bunx playwright install --with-deps chromium

      - run: bun run test:unit -- --run --project=client --project=server

      - run: bun run test:e2e

  deploy:
    needs: test
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pages: write
      id-token: write
    environment: github-pages
    steps:
      - uses: actions/checkout@v4

      - uses: oven-sh/setup-bun@v2
        with:
          bun-version: '1.3.11'

      - uses: actions/setup-node@v4
        with:
          node-version: '24'

      - uses: actions/cache@v4
        with:
          path: ~/.bun/install/cache
          key: bun-${{ runner.os }}-${{ hashFiles('bun.lock') }}
          restore-keys: bun-${{ runner.os }}-

      - run: bun install

      - run: bun run build

      - uses: actions/upload-pages-artifact@v3
        with:
          path: build

      - uses: actions/deploy-pages@v4
```
